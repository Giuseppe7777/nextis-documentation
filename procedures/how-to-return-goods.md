# Як повернути товар постачальнику

> Тип документа: коротка робоча процедура.
> Джерело: українська інструкція, сторінки 23–24; німецька інструкція, сторінки 25–26.
> Статус: Перевірено за PDF.

## Послідовність

1. На верхній панелі вибрати віртуальний склад `Vratka new`.
2. Перейти `Sklad & produkty – PIM` → `Skladové karty (skupiny)`.
3. Перевірити, що залишки відбираються саме для вибраного складу.
4. У списку товарів з натиснутою клавішею `Ctrl` виділити позиції для повернення.
5. Натиснути `Nástroje` → `Naverhnuť prevod na iný sklad`.
6. У списку складів вибрати `Na ceste`.
7. Перевірити створене переміщення перед остаточним проведенням за внутрішніми правилами компанії.

## Логіка операції

Повернення постачальнику в Nextis відображається як переміщення між двома віртуальними складами: `Vratka new` і `Na ceste`.
