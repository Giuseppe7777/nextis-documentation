# Nextis Documentation

Структурована робоча документація для програми Nextis на основі української та німецької PDF-інструкцій.

## Структура

- [`source/`](source/) — відомості про первинні PDF-джерела та контрольні суми.
- [`manual/`](manual/) — нормалізована інструкція за розділами.
- [`procedures/`](procedures/) — короткі алгоритми для типових операцій.
- [`troubleshooting/`](troubleshooting/) — перевірки для типових проблем.
- [`GLOSSARY.md`](GLOSSARY.md) — словник назв кнопок і полів.
- [`DOCUMENTATION_RULES.md`](DOCUMENTATION_RULES.md) — правила доповнення документації.

## Основний принцип

PDF залишається первинним джерелом. Markdown використовується для пошуку, пояснення, Git-історії та поступового доповнення перевіреними робочими знаннями.

## Межі поточної версії

Розділи `Виправлення помилок` і `Звіти` у наданих PDF містять лише заголовки. Відсутні кроки не були вигадані.

Оригінальні PDF і повний комплект скриншотів збережені в підготовленому архіві проєкту. Вони не дублюються в цьому коміті через обмеження підключеного GitHub-інструмента на передавання великих бінарних файлів.
