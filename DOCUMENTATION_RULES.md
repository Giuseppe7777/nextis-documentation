# Правила ведення документації

## Рівні джерел

1. `source/` — первинні PDF або перевірені відомості про них.
2. `manual/` — нормалізований зміст PDF із посиланнями на сторінки.
3. `procedures/` — короткі інструкції для конкретних задач.
4. `troubleshooting/` — перевірені проблеми та способи діагностики.

## Додавання нової інформації

Кожне нове твердження повинно мати один із статусів:

- `Джерело: PDF`;
- `Перевірено в робочій версії Nextis, YYYY-MM-DD`;
- `Припущення — потребує перевірки`.

Припущення не можна подавати як робочу інструкцію.

## Оновлення скриншотів

Новий скриншот отримує змістовну назву, зберігається у відповідній тематичній папці та супроводжується датою перевірки в Markdown-файлі.

## Розбіжності

При розбіжності між PDF і реальною програмою старий текст не видаляється безслідно. Треба записати старий варіант, новий перевірений варіант, версію або дату та джерело перевірки.
